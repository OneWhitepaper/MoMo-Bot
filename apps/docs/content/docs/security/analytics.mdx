---
title: Analytics
description: How analytics is configured in a MoMo bot build.
icon: ChartNoAxesCombined
---

The default MoMo bot build does not initialize an analytics client or send usage events. The desktop launcher does not collect launch statistics.

A maintainer can enable analytics in a specific web interface build by setting `VITE_MOMO_ANALYTICS_TOKEN` to a project token they control. That interface uses PostHog and exposes an analytics control in Settings. Leave the token unset for a build without telemetry.
