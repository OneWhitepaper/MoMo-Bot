---
title: Desktop updates
description: Update MoMo bot manually from a chosen release or source revision.
icon: RefreshCw
---

MoMo bot does not fetch or install updates in the background. Open [Releases](https://github.com/OneWhitepaper/MoMo-Bot/releases) to see what has been published. If there is a package for your platform, quit MoMo bot and run that installer. Reopen the app and check the version in **Settings → About**.

For a source checkout, save your own work before switching to the revision you want. Run `pnpm install --frozen-lockfile` at that revision and restart the development commands in [Installation](/docs/getting-started/installation#run-from-source). If you use a package you built yourself, build and install it again from the chosen revision.

Your settings and chats live outside the checkout and application bundle. See [Data and backups](/docs/self-hosting/data-and-backups) for the directories to save before an upgrade.
