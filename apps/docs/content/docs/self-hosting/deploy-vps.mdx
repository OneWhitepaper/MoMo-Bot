## Build and start the server

Install Node.js 24 or newer and pnpm 10.33.0 on the host. As the account that will run the app, install any agent CLIs you need and sign in to them. Then build the workspace:

```bash
git clone https://github.com/OneWhitepaper/MoMo-Bot.git
cd MoMo-Bot
pnpm install --frozen-lockfile
pnpm build
pnpm build:server
```

For a local server, run `pnpm omb serve`. To pair a desktop across machines, choose one route:

| Connection | Command in the checkout |
|---|---|
| You already have HTTPS through a reverse proxy | `pnpm omb serve --public-url https://bots.example.com` |
| You have a domain and can use the built-in HTTPS setup | `pnpm omb serve --domain bots.example.com` |
| The server and desktop share a Tailscale network | `pnpm omb serve --tailscale` |
| The server and desktop share a private local network | `pnpm omb serve --lan` |

See [Networking](/docs/self-hosting/networking) for the addresses and ports. Keep the full app API off the open internet; configure your intended entry route. The server prints a pairing link. In the desktop app, open **＋ → Connect to a server** and paste it. Run `pnpm omb pair` from the same checkout and account to create another pairing code.

## Run in Docker

To build and run with Docker Compose and automatic HTTPS, use the same checkout on a server with ports 80 and 443 available. Copy `deploy/.env.example` to `deploy/.env`, set `DOMAIN` to your hostname, then run:

```bash
cd deploy
docker compose up -d --build
docker compose exec omb momobot pair
```

The data volume is mounted at `/data`. If you choose to run a prebuilt image instead, set `OMB_IMAGE` to a release tag or digest you trust and use `docker compose up -d --no-build`.

## Keep it running

For an unattended server, run the same `pnpm omb serve` command from your service manager. Set its working directory to the checkout, its account to the one that owns the data and agent logins, and its `PATH` to include Node.js, pnpm, and any agent CLIs. Preserve the same environment and `OMB_DATA_DIR` in administrative commands.

## Back up

Stop the service before taking a filesystem backup. Copy its full data directory, the agent CLI homes and any external working directories your bots use. See [Data and backups](/docs/self-hosting/data-and-backups) for what to keep and how to restore it.

## Update manually

Choose a revision from the [MoMo bot repository](https://github.com/OneWhitepaper/MoMo-Bot). Back up and stop the server, rebuild the chosen revision with the commands above, then start it with the same configuration and data directory. Verify it in the desktop app before removing the prior build and backup.
