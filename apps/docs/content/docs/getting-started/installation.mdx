Check [MoMo bot Releases](https://github.com/OneWhitepaper/MoMo-Bot/releases) for a build for your system. If there is no matching package, run the app from source.

## Run from source

Install Node.js 24 or newer and pnpm 10.33.0, then clone the project:

```bash
git clone https://github.com/OneWhitepaper/MoMo-Bot.git
cd MoMo-Bot
pnpm install --frozen-lockfile
```

Run these three commands in separate terminals, from the checkout:

```bash
pnpm dev:server
pnpm dev --strictPort
pnpm dev:desktop
```

The server listens on `127.0.0.1:8799` and Vite on `127.0.0.1:5199`.

## Connect your AI

Install a supported agent CLI from its provider, sign in, and restart MoMo bot. You can also set an API key for a supported provider. [Agent engines](/docs/providers) lists the options.

If your organization provides a compatible sign-in portal, [connect to it](/docs/getting-started/organisation) to use the models it approves.

## Build a desktop package

Use `pnpm package:mac`, `pnpm package:win`, or `pnpm package:linux` for your platform. The build writes artifacts to `release/`. Distributing signed packages requires signing credentials for the publisher.

## Where data lives

Workspaces and settings start in `~/.momobot`. The desktop puts additional workspaces in `~/.momobot-profiles`; phone pairing uses `~/.momobot-companion`. Existing OpenMausBot data stays in the original application's data directory. See [Data and backups](/docs/self-hosting/data-and-backups) before moving data.
